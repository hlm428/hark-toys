## 😴 催睡觉神器 `/sleep`

帮助你按时放下手机、规律作息的睡前小助手。

- **实时时钟**：大字显示当前时间，可设置计划入睡时间与起床时间。
- **三种语气催睡**：温柔 / 御姐 / 甜妹，每种配有专属晚安语音和 20 条不重样的催睡台词。
- **4-7-8 呼吸放松模式**：吸气 4 秒、屏息 7 秒、呼气 8 秒，跟随动画放松入睡。
- **催睡计数**：记录本次被催了多少次。

## 🌷 双女主百合人设生成器 `/cp-generator`

面向写手和同好的创作灵感工具，专注 GL（双女主）题材。

- **背景与关系可选**：校园、都市职场、古风、娱乐圈、奇幻；青梅竹马、死对头、先婚后爱、双向暗恋等多种关系梗，默认随机。
- **完整人设卡**：名字、年龄、身份、标签、外貌（发型发色、眼睛、身高、穿搭、特征）、性格与反差萌、口头禅。
- **程序化简笔画头像**：根据发型、眼型和配饰实时绘制 SVG 头像，每次生成都不一样。
- **CP 信息卡**：CP 名、关系设定、初遇场景、名场面、甜度 / 虐度星级，以及自动拼接的故事开头。
- **灵活操作**：换一对、只换左边、只换右边、一键复制人设。

## 📚 双女主小说检索站 `/gl-novels`

整理自晋江文学城百合频道榜单（2026 年 10 月）的作品索引。

- **11 个分类**：娱乐圈、都市甜宠、校园青春、古风宫廷、仙侠修真、武侠江湖、末世科幻星际、无限惊悚悬疑、快穿穿书、竞技职场、西幻奇幻。
- **实时搜索**：支持按书名、作者、简介关键词检索，可筛选完结 / 连载。
- **一键直达正版**：每本书都附有晋江官方作品页链接；另附百合轻小说正版出版社入口。
- **随便来一本**：选择困难时随机推荐。

> 仅收录正版链接，部分章节需在原平台订阅，请支持作者。

## 🤪 离谱借口生成器 `/excuses`

需要一个理由，又不想太普通？选好场景、拖动「离谱程度」滑块，一键生成一本正经又离谱的借口。

- **多种场景**可选，离谱程度可调。
- 每条借口附带**可信度**评分，支持换一个、一键复制。
- 记录今日已编借口数量。适合朋友间玩梗，真要请假还是说实话哦。
